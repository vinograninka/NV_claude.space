# NV · Claude — nvclaude.space

Сайт персональной настройки Claude для специалистов и малого бизнеса: https://nvclaude.space

Одна страница на чистом HTML, CSS и JS — без сборки и зависимостей. Открывается двойным кликом по `index.html` и работает на любом статическом хостинге. Сейчас сайт размещён на Timeweb.

## Где что менять

| Что | Файл |
| --- | --- |
| Контакты: Telegram, WhatsApp, телефон, MAX | `src/config/site.js` |
| Сценарии первого экрана, услуги, шаги, карточки задач, частые вопросы | `src/data/content.js` |
| Заголовки и тексты на странице | `index.html` |
| Цвета, шрифты, отступы | `src/styles/main.css` (переменные в начале файла) |
| Анимации и интерактив | `src/js/main.js` |

Цены, сроки и реальные кейсы на сайте намеренно не указаны. Кейсы добавляются в `cases` в `src/data/content.js` — только с подтверждёнными фактами и разрешением клиента.

## Оформление

Фирменный стиль описан в дизайн-системе NV: ночная палитра и «бумажные» разделы, Noto Serif Display + Onest + JetBrains Mono, сценарные цвета apricot, lavender, sage и gold.

## Локальный просмотр

```bash
python3 -m http.server 4173
```

Затем откройте http://localhost:4173.

## Публикация на Timeweb

Загрузите в `public_html` изменённые файлы с сохранением путей (`index.html`, `robots.txt`, `sitemap.xml`, папки `src` и `assets`). После обновления проверьте сайт с жёсткой перезагрузкой: Cmd + Shift + R.

## Движение на странице

- Первый экран: четыре сценария задач. Смена сценария перекрашивает планету, кнопки и акценты, слово уезжает вверх, карточки проекта меняются.
- «Что меняется»: при прокрутке вопросы «до» собираются в карточку «после».
- «Коротко»: звёздное небо, фразы загораются звёздами и соединяются в созвездие.
- «Как это работает»: золотая звезда идёт по маршруту и включает шаги.
- «С какими задачами приходят»: орбиты-направления, связанные с фильтром.

При `prefers-reduced-motion` анимации отключаются, контент показывается сразу.
